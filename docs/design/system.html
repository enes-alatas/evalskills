System design

One shared VPS. Untrusted skill code runs only in gVisor sandboxes on a dedicated Docker daemon. Other apps and the main daemon are untouched

Security
  • No container gets the main Docker socket
  • A: read-only filesystem, all capabilities dropped, non-root
  • The model key lives only in the gateway. Trials get revocable per-run tokens
  • Hard caps per trial, per day and on total spend
Flow
  • Submit a URL, pick skills, a job is queued
  • Static Tier 1 runs for everyone, free and fast
  • Live Tier 3 for approved skills, on shared category tasks, with and without the skill
  • Results are tied to commit and content hash. Unchanged skills are not rerun
Scaling, no redesign
  • More live throughput: raise the concurrency cap, or point the worker at E2B or a second VM (--env-mode, DOCKER_HOST)
  • More traffic: more web replicas behind Caddy, SQLite to Postgres
  • Three containers and one daemon, in one compose file and one systemd unit
